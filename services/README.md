# services/

Директория для локального подключения репозиториев сервисов, исходный код которых AI может анализировать при работе над технической документацией.

## Как подключить сервис

```bash
# вариант 1: клонировать
git clone <service-repo-url> services/<service-name>

# вариант 2: символьная ссылка на локальную копию
ln -s /path/to/service services/<service-name>
```

## Правила

- Содержимое `services/` **не коммитится** в этот репозиторий (`.gitignore`: `services/*`, кроме этого README).
- Код сервисов — source of truth только для **текущей реализации**.
- Requirements (`docs/`) — source of truth для **требуемого поведения**.
- Если код противоречит утверждённому требованию — это фиксируется явно в документации, а не «исправляется» молча в пользу кода.
- AI обращается к `services/` только при создании или проверке `technical.md` (см. `AGENTS.md`).
