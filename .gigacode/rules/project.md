# Правила проекта

Что это за репозиторий, что можно менять, какие инструменты запускать.

## Репозиторий

- Репозиторий документации, не кода. Entry point — `AGENTS.md`, читать первым.
- Ответы и текст документов — русский. Заголовки секций, ID, статусы, `TBD`/`ASSUMPTION` — английские.

## Границы изменений

- Рабочая область — `docs/`. `templates/`, `rules/`, `schemas/`, `scripts/`, `.gigacode/`, `AGENTS.md`, `GIGACODE.md` — только по явному запросу.
- `services/` — только чтение и только для `technical.md`. Не редактировать, не коммитить.
- Новые документы feature — только из `templates/` по таблице «Какие файлы создавать» в `AGENTS.md`.
- Файлы вне `docs/features/<feature>/` и `docs/changes/<change>/` не создавать.
- Менять только запрошенные файлы. Документ целиком не переписывать.

## Инструменты

- Skills — `.gigacode/skills/`. Выбор — раздел «Как определить нужный skill» в `AGENTS.md`.
- Шаги skill выполнять по порядку. Отчёт — по шаблону из секции «Отчёт» skill.
- После каждого изменения `docs/` — `node scripts/validate-docs.mjs`. Завершать работу только при exit 0.
