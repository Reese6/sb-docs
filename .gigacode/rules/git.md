# Правила Git

Коммиты и что в них не попадает.

## Коммиты

- Не коммитить и не пушить без явного запроса человека.
- Один логический блок изменений = один коммит.
- Формат сообщения — `docs(<feature>): <что изменилось>` (`CONTRIBUTING.md`, раздел «Коммиты»).
- Перед коммитом — `node scripts/validate-docs.mjs` с exit 0.

## Не коммитить

- `services/` — кроме `services/README.md`.
- `.gigacode/GIGACODE.local.md` — личные настройки.
