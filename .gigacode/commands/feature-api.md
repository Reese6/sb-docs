# Команда /feature-api

Выполни skill `.gigacode/skills/api-requirements/SKILL.md` целиком: прочитай файл и пройди его секции по порядку — «Вход и стоп-условия», «Прочитать», «Правила», «Шаги», «Чеклист».

Аргументы: {{args}}

Первое слово аргументов — имя feature в kebab-case. Второе и третье слово — метод и путь, например `POST /orders`.
Имя не указано или директории `docs/features/<feature-name>/` нет — остановись и ответь: «Укажи имя feature: /feature-api <feature-name> <METHOD> <path>».
Метод и путь не указаны — составь список методов из требований `requirements.md`, покажи его человеку и остановись до подтверждения. Документ при этом не менять.
Метод и путь указаны — заполни ровно один блок `## <METHOD> <path>`; остальные блоки не трогать.

Отчёт — по секции «Отчёт» из SKILL.md; последнюю строку замени на «Следующая команда: /feature-api <feature-name> <METHOD> <path>» для следующего метода из списка, а когда методы кончились — «Следующая команда: /feature-technical <feature-name>».
