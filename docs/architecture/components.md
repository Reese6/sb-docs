# Components

Компоненты (сервисы) системы и их ответственность. Для каждого сервиса, чей код подключён локально, указывается путь в `services/`.

## Формат описания компонента

- название и назначение (одно предложение);
- ответственность (что делает и что **не** делает);
- ключевые зависимости от других компонентов;
- путь к коду: `services/<service-name>` (если подключён);
- ссылка на API-документацию: `../api/services/<service-name>.md` (если есть).
