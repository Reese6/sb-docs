# Модель данных

Доменная модель данных: сущности, их поля и связи. Уровень — доменный, не физическая схема БД; изменения схемы конкретной feature описываются в её `technical.md` со ссылкой сюда.

## Правила

- Одна сущность — один файл `<entity>.md` в этой директории, имя файла в kebab-case.
- Названия сущностей и полей — из [glossary](../../product/glossary.md).
- Сущность описывается один раз; features ссылаются на файл сущности, не копируют поля.
- Сущности не получают ID.
- Диаграммы — Mermaid (`erDiagram`), если применимо.
- Новая сущность попадает сюда из `model.md` feature через `/feature-apply`.
