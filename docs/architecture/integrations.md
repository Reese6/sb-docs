# Integrations

Интеграции с внешними системами: провайдеры, партнёрские API, инфраструктурные сервисы. Внутреннее взаимодействие компонентов — в [components.md](components.md).

## Формат описания интеграции

- внешняя система и её назначение;
- протокол и формат (REST/gRPC/queue/файловый обмен);
- направление (входящая/исходящая);
- критичность и режим отказа (что происходит при недоступности);
- владелец интеграции.
