# Обзор API

Обзор API продукта: какие API существуют, где документированы, каким глобальным соглашениям подчиняются. Контракты конкретных endpoints — в `api.md` соответствующих features и в `services/` этого раздела.

## Структура раздела

- [authentication.md](authentication.md) — глобальная схема аутентификации и авторизации;
- [conventions.md](conventions.md) — соглашения (нейминг, версионирование, пагинация, форматы);
- [errors.md](errors.md) — единый формат ошибок;
- [services/](services/README.md) — API-документация по сервисам.

## Правило

Глобальные соглашения (auth, ошибки, пагинация) описываются здесь **один раз**. Feature `api.md` ссылается на них и описывает только специфику своих endpoints.
