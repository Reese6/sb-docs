# Персоны

Типовые пользователи продукта. Feature-документация ссылается на personas отсюда, а не описывает пользователей заново.

## Формат persona

Для каждой persona:

- имя-идентификатор (используется в ссылках из features);
- роль и контекст использования продукта;
- ключевые задачи (jobs to be done);
- боли и ограничения.
