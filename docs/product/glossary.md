# Glossary

Единый словарь терминов продукта. **Единственный** источник терминологии: все документы используют термины отсюда и в этих же формулировках (см. `rules/terminology.md`).

## Правила

- Один термин — одна запись, отсортировано по алфавиту.
- Формат: `**Термин** (English term, если есть) — определение.`
- Синонимы запрещены в документации; если синоним встречается в жизни, он указывается в записи с пометкой «не использовать».
- Новый термин добавляется сюда **до** использования в других документах.
- AI не вводит новые термины без добавления в glossary.

## Термины

**OTP** (One-Time Password) — одноразовый код подтверждения, отправляемый пользователю для подтверждения владения учётной записью. Не использовать: «одноразовый пароль», «код из SMS».

**reset_token** — одноразовый токен с ограниченным сроком жизни, выдаваемый после успешного подтверждения OTP; по нему устанавливается новый пароль.

**Интервал повторной отправки** (resend interval) — минимальное время между отправками OTP в рамках одной сессии восстановления пароля. Длительность — TBD.

**Политика паролей** (password policy) — набор требований к допустимому паролю учётной записи. Содержание — TBD.

**Сессия восстановления пароля** (password recovery session) — процесс восстановления доступа от запроса кода до установки нового пароля или завершения по ошибке либо истечению срока, а также персистентное состояние этого процесса (запись с хэшем OTP, счётчиком попыток и сроком действия). Допустимое сокращение: «сессия восстановления».

**Ссылка восстановления** (recovery link) — одноразовая ссылка, отправляемая на email, как альтернативный OTP механизм подтверждения владения учётной записью. В продукте не используется — решение зафиксировано в [adr-001-otp-vs-recovery-link](../features/password-recovery/decisions/adr-001-otp-vs-recovery-link.md).

**Учётная запись** (account) — запись о пользователе продукта, идентифицируемая email; объект восстановления доступа.
