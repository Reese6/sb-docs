# Global business rules

Глобальные бизнес-правила продукта, действующие для всех features. Правило, специфичное для одной feature, живёт в её `requirements.md`; правило, затрагивающее несколько features, живёт здесь — features ссылаются на него по ID, не копируют.

## Формат

Каждое правило имеет стабильный ID `BR-XXX` (стандарт — `../../schemas/README.md`):

```text
BR-001: <формулировка правила>.
Rationale: <почему правило существует>.
```

- ID глобальных BR уникальны в этом файле.
- Изменение правила не меняет его ID; удалённое правило помечается deprecated, ID не переиспользуется.
