# 01. Инициализация проекта

> Источник: INIT.md, ЭТАП 1. Приоритет: P0.
> Зависит от: 00.

## Цель

Создать базовый каркас проекта: Git, директории, корневые документы.

## Шаги

1. Инициализировать Git, если репозиторий ещё не инициализирован.
2. Создать `.gitignore`.
3. Создать основные директории (`docs/`, `templates/`, `skills/`, `rules/`, `schemas/`, `services/`).
4. Создать главный `README.md`.
5. Создать `CONTRIBUTING.md`.
6. Создать `AGENTS.md` (первичная версия; финализация — задача 14).

## Требования к README.md

Объяснить:

- назначение проекта;
- архитектуру документации;
- жизненный цикл документации;
- какие типы документов существуют;
- где находится source of truth;
- как добавить новую feature;
- как AI должен работать с документацией;
- что находится в `services/`.

## Требования к services/ и .gitignore

- `services/` используется для локального подключения репозиториев сервисов, исходный код которых AI может анализировать.
- Содержимое подключённых сервисов не должно попадать в данный Git-репозиторий.
- Настроить `.gitignore` соответствующим образом (игнорировать содержимое `services/`, кроме `services/README.md`).

## Результат (deliverables)

- Инициализированный Git-репозиторий.
- `.gitignore`
- `README.md`
- `CONTRIBUTING.md`
- `AGENTS.md`
- `services/README.md`
- Каркас директорий.

## Критерии готовности

- `git status` работает, репозиторий инициализирован.
- README.md отвечает на все 8 пунктов из списка выше.
- Содержимое `services/*` (кроме README.md) игнорируется Git.
