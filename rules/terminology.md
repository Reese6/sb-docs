# Terminology rules

Правила единой терминологии.

## Единый glossary

Source of truth терминологии — [docs/product/glossary.md](../docs/product/glossary.md). Один.

- Все документы используют термины из glossary в формулировках glossary.
- Синонимы запрещены: одно понятие — один термин во всех документах.
- Если в glossary термина нет — сначала добавить его туда, затем использовать.
- AI не вводит новые термины молча: новый термин = изменение glossary, видимое в diff.

## Правила использования

- Термин пишется одинаково во всех документах (регистр, язык, форма).
- Не переводить устоявшиеся английские термины, зафиксированные в glossary на английском (и наоборот).
- Аббревиатура допустима, только если расшифрована в glossary.
- Если существующий документ использует термин не по glossary — это находка для review, а не повод плодить второй вариант.

## Конфликты

- Два термина для одного понятия → оставить один в glossary, второй пометить «не использовать», документы привести к единому термину.
- Один термин для двух понятий → развести термины в glossary, обновить документы.
- Конфликт решает человек (product owner); AI фиксирует его как находку review.
