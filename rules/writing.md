# Writing rules

Правила стиля и языка документации.

## Язык

- Простой профессиональный язык. Короткие предложения. Одна мысль — одно предложение.
- Прозаический текст — русский; заголовки секций, ID, статусы и ключевые слова (FACT/ASSUMPTION/TBD, draft/approved) — английские.
- Термины — строго по glossary (см. [terminology.md](terminology.md)).

## Запрещён AI-стиль

Не использовать чрезмерно абстрактные и «маркетинговые» формулировки:

- «бесшовный опыт», «мощный функционал», «интуитивно понятный интерфейс», «лучшие практики»;
- вводные без содержания: «важно отметить», «стоит подчеркнуть», «в современном мире»;
- пустые обобщения: «система должна быть гибкой и масштабируемой» без измеримых критериев.

Текст должен нести проверяемую информацию. Если предложение можно удалить без потери смысла — удалить.

## Неизмеримые слова

Запрещены в требованиях без измеримого определения:

```text
удобно
быстро
интуитивно
корректно
нормально
оптимально
```

Неправильно: «Поиск должен работать быстро».
Правильно: «Ответ поиска — не более 500 мс для 95-го перцентиля» (или `TBD: целевое время ответа поиска`).

## Разделение WHAT/WHY и HOW

- **Product documentation** (`product.md`) — WHAT + WHY: проблема, цель, сценарии, ценность. Без деталей реализации.
- **Requirements** (`requirements.md`, `ui.md`, `api.md`) — формализованное ожидаемое поведение. Без выбора технологий.
- **Technical documentation** (`technical.md`) — HOW: решение, компоненты, data flow.
- **ADR** — WHY принято важное техническое решение.

Признаки нарушения:

- в `product.md` упоминаются таблицы БД, очереди, названия библиотек — перенести в `technical.md`;
- в `technical.md` появляется новое требование к поведению — перенести в `requirements.md` с ID;
- в `requirements.md` навязана реализация («хранить в Redis») — оставить требование («кэш с временем жизни N минут»), реализацию — в `technical.md`.

## Структура текста

- Списки — для перечислений, таблицы — для сопоставимых данных, прозаический текст — для объяснений.
- Не дублировать одно содержание в тексте и таблице.
- Примеры — в кодовых блоках.
